# 🧩 Módulos (modules)

En este directorio se almacena el código fuente principal y el **código reutilizable propio de este proyecto**, organizado en diferentes módulos según sus responsabilidades.

Aquí es donde se deben definir las clases, objetos, controladores, y toda la lógica de dominio del sistema orientado a objetos que están construyendo, de manera que puedan ser importados y utilizados desde los scripts en la carpeta `apps` o el archivo principal.

> [!NOTE]
> A diferencia de la carpeta `libs` (que está destinada a código y bibliotecas externas), todo el código modular y propio que ustedes desarrollen para darle comportamiento a este proyecto específico debe residir aquí.
